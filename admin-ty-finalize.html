🧮 Pricing model (Kyle 2026-11-11)

costPrice = COGS from invoice (locked, invariant)
+ adminMargin (15% of cost by default)
= adminPrice (what distributors pay)
+ distributorMargin (20% of cost by default)
= sellPrice (retail)
× 0.95 (flash sale floor — hard rule)
= salePrice (what customers see on /sale.html)

For items already in the catalog with a retail price set, that retail price is kept — only the sale price gets recomputed. The 95% floor is enforced server-side; the system refuses to save anything below it.
